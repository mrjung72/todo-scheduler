개인 사용자와 기업 모두 **무료로 사용**할 수 있고, 기업은 사용자 수에 따라
**연 단위 구독**으로 전환합니다.

## 1. 라이선스 종류

| 종류 | 사용자 수 | 기간 | 비용 |
|------|----------|------|------|
| 무료 키 (free) | 활성 사용자 **5명**까지 | **최대 1년** | 무료 |
| 기업용 키 (ent) | 발급 시 지정한 사용자 수 | 발급 시 지정한 만료일 (연 단위) | 연 구독 (사용자 수 기준) |

- **키는 배포판에 항상 포함**되어 있습니다 — `license.key`가 없거나
  비어 있으면 누락·변조로 보고 조회 전용으로 차단됩니다
- 개인·소규모 팀은 배포판에 포함된 무료 키로 그대로 사용하면 됩니다
- 무료 키는 **최대 1년**까지만 유효하고, **갱신 키를 발급받아 교체하면
  계속 무료로 사용**할 수 있습니다
- 무료 키에서는 **회원가입 기능이 제공되지 않습니다** — 사용자는
  관리자가 관리자 화면의 사용자 탭에서 직접 생성합니다
- 기업에서 5명을 초과해 사용하려면 사용자 수에 맞는 기업용 키를
  발급받아 연 단위로 갱신합니다

> 사용자 수는 `admin` 계정을 제외한 **활성 사용자** 기준입니다.

## 2. 동작 방식

- **사용자 수 제한**: 활성 사용자(`활성(Y)`)가 상한에 도달하면
  **신규 회원가입·승인만 차단**됩니다 — 기존 사용자는 계속 정상 사용
- **만료 임박**: 만료 30일 전부터 화면 상단에 노란 배너로
  `만료까지 N일`이 표시됩니다
- **키 없음·만료·키 변조**: 빨간 배너가 표시되고 조회만 가능 —
  모든 등록·수정·삭제가 차단됩니다 (로그인·회원가입은 가능)

## 3. 키 적용·갱신

- 라이선스 키는 서버의 `app/license.key` 파일에 저장되어 있습니다
- 새 키로 파일을 교체하면 **재기동 없이** 다음 요청부터 즉시 반영됩니다
- 키는 Ed25519 전자서명으로 보호되어 변조하면 인식되지 않습니다
- 키 발급은 배포자가 별도 발급 도구로 수행합니다 — 서버에는
  검증용 공개키만 포함되고 서명용 개인키는 포함되지 않습니다
