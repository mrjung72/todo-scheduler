# TODO 작업 스케줄러 — 사용자 매뉴얼

업무 요청부터 검토·배정·작업·완료까지의 흐름을 상태 기반으로 관리하고,
작업자의 근무일력에 맞춰 작업 일정을 자동으로 계산하는 도구입니다.

---

## 1. 시작하기

### 1.1 접속

- 개발 환경: `http://localhost:5173`
- 운영(배포) 환경: `http://서버주소:8000`

### 1.2 회원가입 및 로그인

1. 화면 우측 상단 **[회원가입]** → ID·비밀번호·이름 등 입력 후 신청
2. 신청 후 상태는 **승인대기(A)** — 관리자가 승인해야 로그인 가능
3. 관리자가 **승인불가(R)** 처리한 경우, 로그인 화면에서 안내 후
   정보를 수정해 **재신청** 가능
4. 로그인 후 우측 상단의 `이름(ID)` 버튼 → **사용자 정보** 팝업에서
   **비밀번호 변경**·**하루작업시간**(개발담당·수석만) 설정 가능

> 비밀번호는 **본인 것만 직접 변경**할 수 있습니다.
> 다른 사용자의 비밀번호는 관리 권한이 있어도 직접 지정할 수 없고,
> **[초기화]**(기본값 1234)만 가능합니다.

### 1.3 사용자 등급

| 등급 | 명칭 | 권한 |
|------|------|------|
| 0 | 관리자 | 모든 기능 + 관리자 화면 전체 권한 |
| 1 | 수석개발자 | 관리자 화면 전체 권한 (admin 계정 정보 변경 제외) |
| 3 | 개발매니저 | 관리자 화면 **전체 조회** + 일반개발자의 사용자정보·휴가 변경 |
| 4 | 일반개발자 | 지정사이트 + 본인 작업만 변경 가능. 관리자 화면은 작업스케쥴·작업이력·작업상태변경이력·첨부파일·사용자(본인 정보만)·작업자휴가(본인만) 탭 사용 |
| 5 | IT업무담당자 | 관리자 화면에서 사이트·작업스케쥴·사용자·달력·작업자휴가 **조회** 가능. 현업담당자·기타사용자의 사용자정보 변경 가능. 작업의 IT담당자로 지정 가능 |
| 7 | 현업담당자 | 작업의 현업담당자(요청자)로 지정 가능 |
| 9 | 기타사용자 | 조회/본인 작업 위주 |

### 1.4 담당분류코드

등급에 따라 사용자에게 **담당분류코드**가 자동 부여됩니다.
분류별 프로세스는 이 코드를 기준으로 동작합니다.

| 분류 | 명칭 | 해당 등급 | 적용되는 프로세스 |
|------|------|----------|------------------|
| A | 어드민 | 0·1 | 관리 기능 전반 |
| D | 개발담당 | 2~4 | **작업자 후보**(수석개발자 포함)·하루작업시간 설정·휴가 등록 |
| B | 업무담당 | 5~7 | **현업담당자(요청자) 후보** |
| G | 기타 | 8·9 | 분류별 프로세스 대상 아님 |

> 담당분류는 등급에서 자동 산출되며 별도로 입력·수정할 수 없습니다.
> 등급을 바꾸면 분류코드도 함께 갱신됩니다.

> **사용자 관리 권한은 등급 계층을 따릅니다.**
> 각 등급은 정해진 하위 등급의 사용자정보만 수정할 수 있고,
> 등급 변경도 관리 범위 내에서만 가능합니다.
> 사용자 목록에는 자신보다 상위 등급의 사용자가 표시되지 않습니다.

> 일반개발자의 지정사이트는 사용자 정보의 **기본사이트** 항목입니다.
> 관리자·수석개발자가 사용자 탭에서 등급을 일반개발자로 바꾸고 기본사이트를
> 지정하면, 해당 사이트의 작업과 본인 작업을 수정할 수 있습니다.

> `admin` 계정은 본인 외에는 누구도(관리자·개발자 포함) 수정할 수 없습니다.

## 2. 작업 상태 체계

작업은 아래 9개 상태 중 하나를 가지며, 화살표 방향으로만 변경할 수 있습니다.
작업의 **스케쥴적용 여부(Y/N)**에 따라 검토중(C) 이후 경로가 갈립니다.

| 코드 | 상태 | 변경 가능한 다음 상태 |
|------|------|----------------------|
| R | 작업요청 | 검토중(C), 작업반려(X) |
| C | 검토중 | 작업반려(X), 대기중(W) — 스케쥴적용 작업 / 단순업무중(O) — 스케쥴미적용 작업 |
| W | 대기중 | 검토중(C), 작업반려(X), 작업중(P) |
| P | 작업중 | 작업반려(X), 작업중단(H), 작업완료(F) |
| H | 작업중단 | 작업중(P), 작업반려(X) |
| O | 단순업무중 | 작업완료(F), 작업반려(X) |
| F | 작업완료 | 최종완료(Z) |
| X | 작업반려 | (종결 — 변경 불가) |
| Z | 최종완료 | (종결 — 변경 불가, 되돌리기도 불가) |

```text
               ┌─(스케쥴적용)──> W ──> P ──> F ──> Z
R ──> C ───────┤                  │ ╲          │
      │        ╰─(스케쥴미적용)─> O ────────> F ╯
      │                       ╰──> H ──> P
      ╰──> X
```

- **스케쥴적용 여부**(관리자 작업스케쥴 탭의 `스케쥴적용` 컬럼, 기본값 Y):
  - **Y (스케쥴적용)**: 기존과 동일하게 `검토중 → 대기중 → 작업중` 경로를 거치고
    자동 스케줄링 대상이 됩니다 — 단순업무중으로 변경할 수 없습니다.
  - **N (스케쥴미적용)**: `검토중 → 단순업무중 → 작업완료` 경로를 거칩니다 —
    대기중 단계로 변경할 수 없고 자동 스케줄링·재계산 대상에서도 제외됩니다.
- **단순업무중(O)으로 변경되면** 작업시작일시가 현재 시각으로 기록됩니다
  (스케줄링과 무관하게 즉시 시작).
- **작업완료(F)는 작업중(P)·단순업무중(O)에서만** 변경할 수 있습니다 — 작업을 완료하려면
  반드시 작업중 또는 단순업무중 상태를 거쳐야 하며, 이 덕분에 실제 작업시간이 자동 집계됩니다.
- **최종완료(Z)는 작업완료(F)에서만** 변경할 수 있고, 최종완료된 작업은
  **어떤 방법으로도 상태를 변경할 수 없습니다** (되돌리기·휴일작업 예외 없음).
  실제종료일시는 작업완료 시각이 유지됩니다.
- **작업중(P)에서 다른 상태로 나갈 때** 해당 구간의 작업시간이 상태변경이력에
  기록되고, 작업의 **실제 작업시간**에 자동 누적됩니다 (직접 수정 불가).
- **작업완료(F)**로 변경되면 종료일시(실제)가 현재 시각으로 기록됩니다.
- **대기중 → 작업중**은 **스케줄된 작업시작일시가 있는 작업만** 가능합니다.
  시작일시가 없거나 미래이면 전환이 차단되며, 시작일시가 지나면
  자동으로 작업중 상태가 됩니다.
- **대기중(W)으로 변경되면** 시작일시·종료(예상)일시·고정 여부가
  **모두 초기화**되어 재계산 전까지 미배치 상태가 됩니다
  (되돌리기로 대기중에 복귀할 때도 동일하게 적용.
  휴일작업은 일시를 수동으로 지정하므로 초기화되지 않습니다).

### 이전 상태로 되돌리기

아래 조건을 만족하면 방금 변경한 상태를 **직전 상태로 되돌릴 수 있습니다**
(칸반에서 직전 상태 칸으로 드래그, 작업스케쥴 상태 셀의 `↩` 버튼 또는
드롭다운의 직전 상태 선택, 작업 상세 팝업의 `↩ 되돌림` 버튼).

- **모든 상태**(최종완료 제외): 상태 변경 후 **1시간 이내**이면
  직전 상태로 되돌리기 가능
- **작업완료(F)·작업반려(X)**: 종료예상시각이 **지나지 않았거나 없으면**
  시간 제한 없이 되돌리기 가능
- **최종완료(Z)**: 되돌리기 불가 — 한 번 최종완료하면 상태 변경 자체가 차단됩니다
- 되돌리기하면 상태변경이력에 `이전 상태로 되돌림`으로 기록되고,
  완료 해제 시 실제종료일시도 함께 해제됩니다
- 되돌리기가 불가능한 경우에는 왜 불가한지 사유가 표시됩니다

### 상태별 수정 가능 항목

| 항목 | R·C·W | O·P·H·F·X·Z |
|------|:-----:|:---------:|
| 유형·작업명·우선순위·예상작업시간·현업담당자·IT업무담당자·작업자 | O | X |
| CSR번호·요청내용·시작일시·상태 | O | O |
| 스케쥴적용 여부 | O (R·C만, 상세 팝업) | X |
| 실제 작업시간 | 자동 집계 (수정 불가) | |

### 작업 유형

| 코드 | 유형 |
|------|------|
| SQ | 단순문의 (Simple Question) |
| FI | 기능개선 (Function Enhancement) |
| BF | 오류수정 (Bug Fix) |
| DE | 데이터추출 (Data Extraction) |
| DM | 데이터변경 (Data Modification) |
| SC | 시스템점검 |
| RS | 연관시스템지원 |
| FW | 장애대응 |
| ET | 기타 |

## 3. 화면 안내

상단 메뉴: **홈(로고) · 칸반 · 달력 · 작업목록 · 게시판 · 관리자**
(관리자 메뉴는 등급 0·1·3·4·5에 표시 — 등급별로 사용 가능한 탭이 다릅니다. §4 참고)

### 3.1 홈 (기본 화면)

진행 중인 업무 현황을 카드로 보여줍니다.

- **작업중(P)** 작업이 맨 위에, 그 아래 **대기중(W)** 작업이 우선순위 순으로 표시
- 카드 위에 **사이트 선택**과 **검색어 입력칸**으로 조회 대상을 좁힐 수 있습니다
- 카드 구성:
  - 1행: 작업번호 · 사이트명 · 유형 · CSR번호 · 상태
  - 2행: 요청자명 · 작업명
  - 3행: 작업자명 · 시작일시 ~ 종료일시 · 예상시간(총 일수)

### 3.2 칸반

작업을 상태별 3열 보드로 보여줍니다.

```text
┌──────────┬──────────┬──────────┐
│  대기중   │  작업중   │ 작업완료  │
│──────────│──────────│          │
│  검토중   │ 작업중단  │          │
│          │──────────│──────────│
│ 작업요청  │단순업무중 │ 최종완료  │
│          │          │──────────│
│          │          │ 작업반려  │
└──────────┴──────────┴──────────┘
```

- 카드를 **드래그**해서 다른 영역으로 옮기면 상태가 변경됩니다
  (전이 규칙에 맞지 않는 이동은 거부되며, 오류 메시지는 잠시 후 자동으로 사라집니다)
  - 이동이 거부되면 **이동 가능한 상태와 되돌리기 가능 여부**가
    오류 메시지에 함께 표시됩니다
  - 직전 상태 칸으로 드래그하면 **상태 되돌리기**가 실행됩니다 (§2 참고)
- 카드 1행에 `#작업ID`가 표시되고, 우선순위 0 작업은 빨간 `긴급` 배지가 붙습니다
- 카드 2행은 요청자+작업명을 한 줄로 표시 (작업명이 길면 `…` 말줄임,
  마우스를 올리면 전체 이름 표시), 3행은 작업자명과 작업기간을 표시합니다
- 카드를 **클릭하면 선택 카드가 다른색 배경으로 강조**됩니다 —
  드래그로 옮긴 후에도 다른 카드를 선택하기 전까지 강조가 유지됩니다
- **휴일작업** 카드에는 주황색 `휴일` 배지가 표시됩니다
- **단순업무중(O)** 카드의 작업기간은 `시작일시 ~ 시작일시+예상작업시간`으로
  표시됩니다 (자동 스케줄링과 무관한 단순 시간 가산)
- 사이트·유형·**요청자**·작업자·키워드로 필터링 가능
  (요청자는 이름 입력 시 `이름 (ID)` 후보가 검색됩니다), 카드 클릭 시 상세 팝업

### 3.3 달력

작업 일정을 월/주 단위 달력으로 보여줍니다.

- 대기중·작업중 작업이 시작~종료 기간 동안 색상 바로 표시
- 이벤트 타이틀 맨 앞에 `#작업ID`와 **우선순위 배지**가 표시됩니다
  (우선순위 0은 숫자 대신 빨간 `긴급` 배지로 표시)
- 빨간 배경 = 휴일, 주황 배경 = 작업자 휴가 (종일뿐 아니라 **일부/반차 휴가도 표시**)
  - 일부 휴가는 선택한 시간대 위치만 채워집니다 (오전=앞쪽, 오후=뒤쪽)
  - 작업바에서 휴가·고정작업 등으로 작업 불가한 구간은 **연하게** 표시됩니다
- **휴일작업** 이벤트에는 주황색 `휴일` 배지 표시
- 날짜당 작업이 **4줄을 넘으면** `+n more`로 접힘 (클릭 시 전체 팝업)
- 검색조건: 사이트·유형·**요청자**·작업자·키워드 + **[작업자휴가] 체크박스**
  (해제 시 개인 휴가 숨김, 작업자/키워드 검색은 휴가에도 적용)
  + **작업 구분 선택** — `스케쥴링작업`(기본) / `비스케쥴링작업` / `전체`.
    비스케쥴링작업 선택 시 단순업무중(O) 작업이 달력에 표시됩니다
    (작업바 = 시작일시 ~ 시작일시+예상작업시간, 자동 스케줄링과 무관)
- **날짜 숫자 클릭**: 권한이 있는 사용자는 휴일/휴가 입력 팝업이 열리고,
  기존 휴가가 있는 날은 같은 팝업에서 **수정·삭제** 가능
  (날짜 칸의 빈 공간 클릭은 무시됩니다. 휴가 변경 시 해당 작업자 일정이
  자동 재계산됩니다. IT업무담당자는 조회만 가능)
  - 휴가 구분 `일부(시간)` 선택 시 **오전/오후**를 추가로 선택합니다
  - 팝업의 작업자는 **본인으로 기본 설정**됩니다 (관리자·수석은 변경 가능)
- 이벤트 클릭 시 작업 상세 팝업

### 3.4 작업목록

전체 작업을 표로 조회합니다.

- 첫 컬럼에 **작업ID**가 표시됩니다
- 우선순위 0 작업은 **작업명 앞에 빨간 `긴급` 배지**가 표시됩니다
- 사이트·상태·유형·**요청자**·작업자·키워드 검색, [검색조건 저장]으로 조건 보관
  - 키워드는 작업명·**CSR번호**·요청자/IT담당/작업자 이름·ID로 검색됩니다
- 현업담당자·IT담당자·작업자의 **이름을 클릭**하면 해당 사용자의
  정보(등급·담당분류·부서·연락처 등) 팝업이 열립니다
- 페이지당 20건, 하단에서 페이지 이동 및 총 건수 확인
- **[엑셀 다운로드]**: 조회된 전체 데이터를 CSV로 저장 (파일명에 검색조건 반영)

### 3.5 작업 상세 팝업

어느 화면에서든 작업을 클릭하면 열립니다. 타이틀을 드래그해 **위치를 옮기거나**,
우하단 모서리를 드래그해 **크기를 조절**할 수 있습니다.

- **타이틀**: 1행 [`#작업ID`] [`우선순위 N`] [사이트] [유형] CSR번호 [휴일작업] [상태], 2행 작업명
  (우선순위 0은 `우선순위 N` 대신 빨간 `긴급` 칩으로 표시)
  - CSR번호·작업명 옆의 **복사 아이콘**으로 한 클릭 복사 (작업색의 보색 버튼,
    복사 시 `복사되었습니다` 표시)
  - 되돌리기 가능한 작업은 상태 칩 옆에 **`↩ 되돌림`** 버튼이 표시됩니다 (§2 참고)
- **작업정보**: 요청자/작업자(이름+직급/팀명)·우선순위·예상시간(총 일수·**작업자의 하루작업시간** 표기)·
  **스케쥴(적용/미적용)**·요청일자·시작·종료(예상) — 우측에 일별 작업시간 표(휴가일 표시)
  - **우선순위·예상시간·시작일시·요청일자**는 [수정]으로 인라인 변경 가능
    (수정 권한이 있고 작업요청·검토중·대기중 상태이거나 휴일작업일 때)
  - **스케쥴**은 작업요청·검토중 상태에서 [수정]으로
    `적용 (스케쥴링 작업)` / `미적용 (단순업무)` 전환 가능 — 미적용이면
    `검토중 → 단순업무중` 경로로 진행됩니다 (§2 참고)
  - 시작일시를 수동으로 설정하면 자동으로 **고정**되며 `고정` 배지가 표시,
    [고정해제]로 해제 가능 — 시작일시·예상시간 변경 시 종료예상일시와
    일별 작업시간이 자동 재계산됩니다
  - **종료(예상)** 옆의 **[작업스케쥴링 재실행]** 버튼으로 대기중 작업의
    일정을 우선순위 기준으로 즉시 재계산할 수 있습니다
    (관리자·수석은 전체, 그 외 등급은 본인 작업이 대상.
    **스케쥴미적용 작업에는 표시되지 않습니다**)
- 팝업 하단은 **`작업요청내용` / `작업이력` / `상태변경이력` 3개 탭**으로 구성되고,
  각 탭의 조작 버튼은 탭 바 우측에 표시됩니다
  (탭을 전환해도 팝업 크기는 유지됩니다)
- **작업요청내용 탭**: 요청내용 + 첨부파일
  - 권한이 있으면 탭 바의 [수정]으로 요청내용을 인라인 편집 가능
  - 첨부파일은 파일명 클릭 시 브라우저 다운로드로 저장 (대용량 파일도
    진행률이 표시됩니다), 권한이 있으면 파일 첨부 가능
  - 업로드 시 진행상태바가 표시되며, 실행파일 등 부적절한 확장자는 차단됩니다
- **작업이력 탭**: 작업자의 수동 작업 기록을 전체 너비로 표시
  - 탭 바의 [등록]으로 작성, 작업내용 클릭 시 상세 팝업
    (드래그 이동·크기 조절 가능. 본인 이력 또는 스태프는 팝업에서
    수정·파일 첨부 가능. 내용이 소스 코드로 인식되면 언어 자동 하이라이트)
- **상태변경이력 탭**: 상태 전이 기록을 전체 너비로 표시 (등록일시 **초단위**)
  - 관리자·수석개발자는 탭 바의 **[초기화]** 버튼으로 해당 작업의 이력을
    초기화할 수 있습니다 (삭제 후 현재 상태의 `이력 초기화` 기록 1건이 남습니다)
- 팝업 하단에 [닫기] 버튼 배치
- 우선순위·예상시간·스케쥴적용·시작일시·요청일자·요청내용은 팝업에서도 수정 가능하고,
  그 외 항목 수정은 관리자 작업스케쥴 목록의 셀 수정으로 처리합니다

### 3.6 게시판

공지·자료 공유용 게시판입니다.

- **글 작성**: [글쓰기]로 제목·내용 입력 + 파일 첨부 (여러 파일 선택 시
  저장과 함께 업로드) — 공개/비공개 선택 가능
- **비공개 글**: 비밀번호를 설정하면 비밀번호를 아는 사용자만 열람
  (작성자·관리자는 비밀번호 없이 열람 가능, 목록에는 🔒·`비공개` 표시)
- **글 열람**: 제목 클릭 시 상세 팝업 (드래그 이동·크기 조절 가능)
  - 첨부파일 목록·다운로드, 댓글 등록·삭제
  - 작성자·관리자는 팝업에서 바로 파일 업로드 가능
- **수정·삭제**: 작성자 또는 관리자만 가능

## 4. 관리자 화면

등급별 사용 가능한 탭과 변경 권한은 다음과 같습니다.

| 등급 | 사용 가능 탭 | 변경 권한 |
|------|-------------|-----------|
| 0 관리자 | 전체 | 전체 |
| 1 수석개발자 | 전체 | 전체 (admin 계정 제외) |
| 3 개발매니저 | 전체 (조회) | 일반개발자의 사용자정보·휴가만 |
| 4 일반개발자 | 작업스케쥴·작업이력·작업상태변경이력·첨부파일·사용자·작업자휴가 | 지정사이트·본인 작업, 본인 휴가·개인정보 |
| 5 IT업무담당자 | 사이트·작업스케쥴·사용자·달력·작업자휴가 (조회) | 현업담당자·기타사용자의 사용자정보 |

탭 순서:

`사이트 → 작업스케쥴 → 작업이력 → 작업상태변경이력 → 첨부파일 → 사용자 → 달력 → 작업자휴가 → 게시판`

새로고침해도 **마지막으로 보던 탭이 그대로 유지**됩니다
(브라우저 세션 단위로 저장, 권한이 없는 탭이면 작업스케쥴로 이동).

### 공통 기능

- 각 탭 상단의 **검색라인**(사이트·상태·키워드)으로 목록 필터링
- **[검색조건 저장]**: 현재 필터를 브라우저에 저장, 다음 접속 시 자동 복원
- **[새로고침]**: 검색조건 저장 버튼 옆의 버튼으로 목록 즉시 재조회
  (클릭 시 `갱신 중…` 표시)
- 아래 **입력라인**에서 신규 항목 등록
- 모든 목록 **페이지당 20건** + 총 건수 표시
- **[엑셀 다운로드/업로드]**: CSV로 내보내기·일괄 수정 반영

### 4.1 사이트

사이트(시스템/고객사) 등록·수정·삭제. 작업 등록 시 선택하는 사이트 목록을 관리합니다.

### 4.2 작업스케쥴 (기본 탭)

작업의 등록부터 상태·일정까지 한 곳에서 관리합니다.

- **검색라인**: 사이트·상태·유형·**요청자**·**작업자**·키워드 필터
  - 요청자는 이름 입력 시 `이름 (ID)` 후보가 검색되어 선택합니다
  - 기본값은 저장된 검색조건이 없으면 사이트=본인 기본사이트,
    상태=작업요청으로 열립니다 ([검색조건 저장]한 값이 있으면 그것이 우선)
- **입력라인**: 사이트·유형·CSR번호·현업담당자·작업자·작업명 순
  (CSR번호 외 모두 필수 입력) + 긴급·휴일작업·스케쥴적용 체크 후 **[작업추가]**
  → **스케쥴적용 체크를 해제**하면 스케줄링 없이 바로 처리하는
    **단순업무** 작업으로 등록됩니다 (`검토중 → 단순업무중 → 작업완료` 경로, §2 참고)
  → 현업담당자 후보는 **업무담당(B)** 사용자, 작업자 후보는
    **개발담당(D)+수석개발자** 사용자입니다
  → 상태는 자동으로 **작업요청(R)**, 요청일시는 등록 시각으로 기록
  → 사이트는 **본인 기본사이트가 자동 선택**되고, 그 사이트의
    **IT담당자가 자동 적용**됩니다
  → **우선순위는 작업ID로 자동 부여** (등록 순서), **[긴급] 체크 시 0**으로
    설정되어 목록·스케줄링에서 최우선 배치
  → 예상작업시간은 **기본 4시간** 자동 적용, 상세내용은 등록 후
    상세 팝업에서 입력
  → **CSR번호는 기등록 여부를 체크**하여 중복이면 등록·수정 모두 거부됩니다
  → 작업명은 최대 **100자** (목록에는 25자까지만 표시되고 `…` 말줄임,
    작업명 클릭 시 상세 팝업)
  → 새 작업은 목록에서 바로 표시되고 해당 행으로 스크롤·강조됩니다
    (검색조건이 자동으로 작업요청 상태로 적용)
- **목록 컬럼**: ID · 사이트 · 유형 · 작업명 · 우선순위 · 요청일시 ·
  작업시간(예상/실제 한 행) · 상태 · **스케쥴적용** · CSR번호 · 현업담당자 ·
  IT업무담당자 · 작업자 · 시작일시 · 종료일시
  - 스케쥴적용 컬럼은 R·C 상태에서 `Y/N` 수정 가능 — `N`이면 단순업무
    (자동 스케줄링 제외, `검토중 → 단순업무중` 경로)
  (완료 전=예상종료일시, 완료 후=실제종료일시)
  - 우선순위 0 작업은 **작업명 앞에 빨간 `긴급` 배지**가 표시됩니다
- **셀 클릭 수정**: 유형·CSR·담당자·작업자를
  행에서 바로 수정 (P·H·F·X·Z 상태에서는 일부 항목 잠김 — §2 참고)
  - **작업명·우선순위·작업시간·상태·스케쥴적용** 컬럼은 **조회 전용**입니다 —
    우선순위·예상시간·스케쥴적용은 상세 팝업에서, 상태는 칸반 드래그나
    상세 팝업에서 변경합니다
  - 현업담당자 셀은 이름을 입력하면 실시간으로 목록이 필터링됩니다
  - 담당자·작업자는 **이름으로 표시**되며, 셀의 `ⓘ` 버튼을 누르면
    해당 사용자의 정보 팝업이 열립니다
  - 되돌리기 가능한 작업의 상태 셀에는 `↩` 버튼이 표시됩니다 (§2 참고)
- **시작일시·요청일시 클릭**: 팝업에서 날짜·시간을 선택해 수정
  (요청일시는 상태와 무관하게 수정 가능)
  - 시작일시는 **[고정]** 체크로 수동 고정 가능 — 고정 시 재계산에도 유지됩니다
  - 일반 작업은 시작일을 **휴일·주말로 지정할 수 없습니다**
- **휴일작업 체크**: 휴일·주말에 수행하는 작업으로 지정
  - 자동 스케줄링 대상에서 제외되며 시작·종료일시를 수동으로 지정합니다
  - 지정한 기간에 근무일(평일)이 포함되면 경고가 표시됩니다
  - 작업완료(F)·작업반려(X)·최종완료(Z)된 휴일작업은 달력에 표시되지 않습니다
- **[재적용]**: 대기중 작업들의 일정을 우선순위 순으로 다시 자동 배치
  - 고정·휴일작업과 배치된 작업의 기간은 제외하고 가장 빠른 빈 시간부터
    배치합니다 (§5 자동 스케줄링 규칙 참고)
- **작업명 클릭**: 작업 상세 팝업 / **삭제**: R·C·W·H·X 상태에서만 가능
- **엑셀 업로드**: 다운로드한 CSV를 수정해 올리면 일괄 반영
  (실제 작업시간은 자동 집계라 업로드로 변경되지 않습니다)

### 4.3 작업이력

작업자가 실제 수행한 작업의 기록(일지)입니다. 상태 전이와 무관하게
작업자가 직접 등록하는 수동 기록입니다.

- 목록 컬럼: **작업ID · 작업명 · 작업스케쥴ID · 작업자** · 작업내용 · 등록일시
  - **작업명 클릭** 시 해당 작업의 상세 팝업이 열립니다
  - **작업내용은 한 줄로 말줄임 표시**, 클릭 시 작업 상세 팝업의 작업내용 창과
    동일한 팝업이 열립니다 (드래그 이동·크기 조절·소스 하이라이트·첨부)
- 작업 선택 + 작업자 선택 + 작업내용 입력 → [등록]
- 등록 후에는 **작업내용만 수정** 가능 (작업·작업자는 변경 불가,
  목록에서 직접 수정 또는 작업내용 팝업에서 수정)
- 삭제 가능
- **작업 상세 팝업의 [작업이력] 탭에서도** 등록·수정·파일 첨부 가능

### 4.4 작업상태변경이력

모든 작업의 상태 변경 기록입니다 (자동 생성, 수정 불가).

- 작업ID · 이력ID · 변경 시각 · 작업 · **변경자**(상태를 바꾼 사용자) ·
  변경 상태 · 작업기간(h) · 비고 표시
- 사이트·상태·작업 선택·키워드로 검색
- [전체삭제]: 이력 초기화 (주의 — 복구 불가)

### 4.5 첨부파일

작업에 첨부된 파일 목록을 관리합니다.

- 목록 컬럼: 작업ID · 작업명 · 작업자 · 작업스케쥴ID · 파일ID ·
  파일명 · 첨부파일경로 · 등록일시 · 삭제
- 작업을 고르고 파일 선택 후 [업로드] — 진행상태바 표시,
  실행파일 등 부적절한 확장자는 차단됩니다
- **파일명을 클릭하면 다운로드** — 브라우저 다운로드로 저장되어
  대용량 파일도 진행률이 표시됩니다 (인라인 수정 기능 없음)
- 사이트·작업 상태·키워드로 검색 가능 (작업자 검색 포함)

### 4.6 사용자

계정 승인과 정보를 관리합니다.

- 회원상태는 상태명으로 표시: 활성(Y) / 승인대기(A) / 승인불가(R) / 비활성(N)
- **담당분류** 컬럼에 분류명(어드민/개발담당/업무담당/기타) 표시 —
  등급에서 자동 산출되어 직접 수정은 불가 (§1.4 참고)
- **등록일자** 컬럼에 계정 생성일 표시
- **승인대기(A)** 사용자의 [승인]/[승인불가] 처리
  - 승인불가 시 사유 입력 가능 — 해당 사용자는 재신청 가능
- 이름·부서·연락처·등급·기본사이트·**하루작업시간** 등 인라인 수정
  - 수정 가능한 범위는 등급 계층을 따릅니다 (§1.3 참고)
  - 본인 행은 누구나 개인정보 항목(이름·연락처·하루작업시간 등)을 수정 가능
- **검색라인**: **사이트**(기본사이트 기준)·상태·**담당분류**·등급 필터 + 키워드 검색
- **하루작업시간**: 작업자별 하루 배정 시간 (선택 상자에서 2~8시간 정수,
  `기본` 선택 시 `.env` 근무구간 합계 적용)
  - **개발담당(D)+수석개발자만** 설정 가능 — 그 외 사용자는 항목이
    표시되지 않고, 작업자가 아닌 등급으로 변경되면 자동 초기화됩니다
  - 신규 사용자 추가 폼에는 기본값이 자동 선택됩니다
  - 변경하면 해당 작업자의 대기 작업 일정이 **자동 재계산**됩니다
  - 본인은 프로필 팝업(`이름(ID)` 버튼)에서도 변경 가능
- **비밀번호**: 본인 행에는 [변경] 버튼(직접 입력), 타인 행에는
  [초기화] 버튼(기본값 1234으로 리셋)만 표시 — 관리자도 타인의
  비밀번호를 직접 지정할 수 없습니다
- 사용자 삭제
- `admin` 행은 잠금(🔒 보호) — 어떤 사용자도 수정 불가

### 4.7 달력

전역 근무일력을 관리합니다.

- 좌측: 연도·월 선택 → 해당 월의 날짜별 근무일(W)/휴일(H) 지정
- 우측: 연도 입력 후 **[해당 연도 달력 생성]** → 1년치 날짜 일괄 생성
  (기본 평일=근무일, 주말=휴일)
- 달력 편집은 관리자·수석개발자(0·1)만 가능 — 개발매니저·IT업무담당자는 조회 전용
- 달력에 없는 날짜는 월~금이 근무일로 간주됩니다

### 4.8 작업자휴가

작업자별 휴가 등록·관리 — 스케줄 계산에 반영됩니다.

- **A(종일)**: 해당일 전체 근무 제외
- **P(일부-오후)**: 지정한 시간만큼 그날 근무의 **뒤쪽**부터 차감
- **M(일부-오전)**: 지정한 시간만큼 그날 근무의 **앞쪽**부터 차감
  - 차감 기준은 해당 작업자의 **하루작업시간**입니다
  - 일부 휴가 시간이 작업자의 하루작업시간 이상이면 그날은 종일 휴가로 표시
- 휴가 등록·수정·삭제 시 해당 작업자의 대기 작업 일정이 자동 재계산됩니다
- 권한:
  - 본인 휴가는 본인이 등록·수정 (달력 날짜 클릭으로도 가능)
  - 관리자·수석개발자(0·1)는 모든 작업자의 휴가 관리 가능
  - 개발매니저(3)는 일반개발자(4)의 휴가를 등록·수정·삭제 가능
  - **IT업무담당자(5)는 조회만 가능** (등록·수정·삭제 불가)

### 4.9 게시판

게시판 글을 관리합니다 (개발매니저는 조회 전용).

- **검색라인**: 공개여부(전체/공개/비공개) + 제목·작성자 키워드
- **목록 컬럼**: 번호 · 제목 · 공개여부 · 비밀번호 · 작성자 · 첨부/댓글 수 ·
  작성/수정일시 · 삭제
- **제목 클릭**: 본문·첨부파일(다운로드)·댓글 열람 팝업
  (드래그 이동·크기 조절 가능, 스태프는 댓글 삭제 가능)
- **공개여부 셀**: 공개↔비공개 전환 (공개 전환 시 비밀번호 자동 해제)
- **비밀번호 셀**: [해제]로 비밀번호 초기화 — 작성자가 비밀번호를
  잊었을 때 사용
- **삭제**: 첨부파일·댓글과 함께 게시글 삭제
- **[엑셀 다운로드]**: 게시글 목록 CSV 내보내기

## 5. 자동 스케줄링 규칙

- **기본 근무구간**: `.env`의 `WORK_SEGMENTS`로 정의
  (현재 10:00~16:00 = 6시간/일, 화면 상단에 표시)
- **작업자별 하루작업시간**: 사용자 정보의 `하루작업시간`으로 하루 배정 시간을
  작업자마다 다르게 지정 가능 (2~8시간 정수)
  - 미설정(`기본`)이면 근무구간 합계가 적용됩니다
  - 근무구간보다 **짧게** 설정 → 하루 앞쪽부터 그 시간까지만 배정
    (예: 4시간 → 10:00~14:00)
  - 근무구간보다 **길게** 설정 → 마지막 근무구간의 종료가 연장됩니다
    (예: 8시간 → 10:00~18:00)
  - 값을 변경하면 해당 작업자의 대기 작업이 즉시 재계산됩니다
- **비근무일**: 토·일 + 달력 탭에서 휴일(H)로 지정한 날
  (평일이라도 휴일로 지정되면 작업이 배치되지 않습니다)
- **작업자 휴가**: 종일(A)은 근무 제외, 일부는 작업자의 하루작업시간 기준으로
  시간 차감 — 오후(P)는 하루 뒤쪽부터, 오전(M)은 앞쪽부터 차감합니다.
  휴가 변경 시 일정이 자동 재계산됩니다
- **배치 방식**: 작업자별로 **우선순위 순** 정렬 → 가장 빠른 빈 시간부터
  근무시간에 맞춰 시작/종료(예상) 자동 계산
  - **점유구간 제외**: 고정 시작·휴일작업·이미 배치된 작업의 기간은
    작업 불가 시간으로 보고 건너뜁니다 — 작업이 그 기간을 끼고
    앞뒤로 이어서 배치될 수 있습니다 (일별작업시간에서도 해당 기간은 제외)
  - 단, **나보다 우선순위가 높은 고정 작업**이 있으면 그 종료 이후부터만
    배치됩니다 (앞의 빈 날은 쓰지 않습니다)
- **시작일시 고정**: 고정된 작업은 재계산에도 시작일시 유지
- **자동 작업중 전환**: 대기중 작업의 시작예정시간이 지나면
  자동으로 작업중(P) 상태가 됩니다
  - 스케줄된 작업시작일시가 없는 대기 작업은 작업중으로 변경할 수
    없습니다 — [재적용]으로 시작일시를 배정받아야 합니다
- **휴일작업**: 위 규칙의 예외 — 휴일·주말을 포함해 기간을 수동 지정하며
  자동 배치 대상이 아닙니다 (기간에 근무일이 섞이면 경고)
- 작업 시작일시가 잡히면 예상시간을 근무시간 단위로 쪼개
  일별 작업시간(상세 팝업에서 확인)이 계산됩니다

## 6. 자주 묻는 상황

| 상황 | 방법 |
|------|------|
| 작업 등록 | 관리자 → 작업스케쥴 입력라인에서 [작업추가] |
| 작업 진행 시작 | 상태를 대기중 → 작업중으로 변경 (목록 셀·칸반 드래그·상세 팝업). 시작예정시간이 지난 대기 작업은 자동으로 작업중 전환. 시작일시가 스케줄되지 않은 작업은 [재적용] 필요 |
| 작업이 잠시 멈춤 | 작업중 → 작업중단, 재개 시 작업중단 → 작업중 |
| 상태를 잘못 바꿈 | 1시간 이내면 직전 상태로 되돌리기 — 칸반에서 직전 상태 칸으로 드래그, 작업스케쥴 상태 셀 `↩`, 상세 팝업 `↩ 되돌림` (완료·반려는 예상시각 미경과 시 제한 없음) |
| 요청 거절 | 작업반려(X)로 변경 (사유는 상태 비고에 기록) |
| 특정 날부터 시작 지정 | 작업스케쥴 시작일시 셀 클릭 → 일시 입력 + 고정 |
| 휴일·주말 작업 | 작업스케쥴 목록에서 휴일작업 체크 후 기간 수동 지정 |
| 전체 일정 재조정 | 우선순위 수정 후 작업스케쥴의 [재적용] |
| 작업자별 하루 시간 변경 | 사용자 탭 또는 프로필 팝업에서 하루작업시간 선택 (대기 작업 자동 재계산) |
| 공휴일 지정 | 관리자 → 달력 탭에서 해당일을 휴일(H)로 |
| 연차·반차 등록 | 관리자 → 작업자휴가 탭 (반차는 일부-오전/오후 + 시간), 또는 달력에서 날짜 숫자 클릭 |
| 비밀번호 변경 | 프로필 팝업(본인) 또는 사용자 탭 본인 행 [변경] / 타인은 [초기화]만 가능 |
| 작업일지 기록 | 관리자 → 작업이력 탭에서 작업내용 등록 |
| 파일 공유 | 작업 상세 팝업 → 첨부, 또는 관리자 → 첨부파일 탭 |
