# TODO 작업 스케줄러 — 사용자 매뉴얼

업무 요청부터 검토·배정·작업·완료까지의 흐름을 상태 기반으로 관리하고,
작업자의 근무일력에 맞춰 작업 일정을 자동으로 계산하는 도구입니다.

---

## 1. 시작하기

### 1.1 접속

- 개발 환경: `http://localhost:5173`
- 운영(배포) 환경: `http://서버주소:8000`

### 1.2 회원가입 및 로그인

1. 화면 우측 상단 **[회원가입]** → ID·비밀번호·이름 등 입력 후 신청
2. 신청 후 상태는 **승인대기(A)** — 관리자가 승인해야 로그인 가능
3. 관리자가 **승인불가(R)** 처리한 경우, 로그인 화면에서 안내 후
   정보를 수정해 **재신청** 가능
4. 로그인 후 우측 상단의 `이름(ID)` 버튼 → **사용자 정보** 팝업에서
   **비밀번호 변경** 가능

### 1.3 사용자 등급

| 등급 | 명칭 | 권한 |
|------|------|------|
| 0 | 관리자 | 모든 기능 + 관리자 화면 |
| 1 | 개발자 | 관리자 화면 전체 탭 사용 가능 (admin 계정 제외) |
| 2 | IT업무담당자 | 작업의 IT담당자로 지정 가능 |
| 3 | 현업담당자 | 작업의 현업담당자(요청자)로 지정 가능 |
| 9 | 기타사용자 | 조회/본인 작업 위주 |

> `admin` 계정은 본인 외에는 누구도(관리자·개발자 포함) 수정할 수 없습니다.

## 2. 작업 상태 체계

작업은 아래 7개 상태 중 하나를 가지며, 화살표 방향으로만 변경할 수 있습니다.

| 코드 | 상태 | 변경 가능한 다음 상태 |
|------|------|----------------------|
| R | 작업요청 | 검토중(C), 작업반려(X) |
| C | 검토중 | 작업반려(X), 대기중(W), 작업완료(F) |
| W | 대기중 | 검토중(C), 작업반려(X), 작업중(P), 작업완료(F) |
| P | 작업중 | 작업반려(X), 작업중단(H), 작업완료(F) |
| H | 작업중단 | 작업중(P), 작업반려(X), 작업완료(F) |
| F | 작업완료 | (종결 — 변경 불가) |
| X | 작업반려 | (종결 — 변경 불가) |

```text
R ──> C ──> W ──> P ──> F
│     │     │     │ ╲
│     │     │     ╰──> H ──> P
╰──> X ╰──> X ╰──> X
```

- **작업중(P)에서 다른 상태로 나갈 때** 해당 구간의 작업시간이 상태변경이력에
  기록되고, 작업의 **실제 작업시간**에 자동 누적됩니다 (직접 수정 불가).
- **작업완료(F)**로 변경되면 종료일시(실제)가 현재 시각으로 기록됩니다.
- 대기중 작업에 시작일시가 미래로 잡혀 있으면 작업중으로 바로 전환할 수 없습니다.

### 상태별 수정 가능 항목

| 항목 | R·C·W | P·H·F·X |
|------|:-----:|:-------:|
| 유형·작업명·우선순위·예상작업시간·현업담당자·IT업무담당자·작업자 | O | X |
| CSR번호·요청내용·시작일시·상태 | O | O |
| 실제 작업시간 | 자동 집계 (수정 불가) | |

### 작업 유형

| 코드 | 유형 |
|------|------|
| SQ | 단순문의 (Simple Question) |
| FI | 기능개선 (Function Enhancement) |
| BF | 오류수정 (Bug Fix) |
| DE | 데이터추출 (Data Extraction) |
| DM | 데이터변경 (Data Modification) |

## 3. 화면 안내

상단 메뉴: **홈(로고) · 칸반 · 달력 · 작업목록 · 관리자** (관리자 메뉴는 등급 0·1만 표시)

### 3.1 홈 (기본 화면)

진행 중인 업무 현황을 카드로 보여줍니다.

- **작업중(P)** 작업이 맨 위에, 그 아래 **대기중(W)** 작업이 우선순위 순으로 표시
- 카드 구성:
  - 1행: 작업번호 · 사이트명 · 유형 · CSR번호 · 상태
  - 2행: 요청자명 · 작업명
  - 3행: 시작일시 ~ 종료일시 · 예상시간(총 일수)
- 카드 클릭 시 상세 정보(담당자·요청내용·첨부파일·상태이력) 팝업

### 3.2 칸반

작업을 상태별 3열 보드로 보여줍니다.

```text
┌──────────┬──────────┬──────────┐
│  검토중   │  대기중   │ 작업완료  │
│──────────│──────────│          │
│ 작업요청  │  작업중   │          │
│          │──────────│──────────│
│          │ 작업중단  │ 작업반려  │
└──────────┴──────────┴──────────┘
```

- 카드를 **드래그**해서 다른 영역으로 옮기면 상태가 변경됩니다
  (전이 규칙에 맞지 않는 이동은 거부됩니다)
- 사이트·키워드로 필터링 가능, 카드 클릭 시 상세 팝업

### 3.3 달력

작업 일정을 월/주 단위 달력으로 보여줍니다.

- 대기중·작업중 작업이 시작~종료 기간 동안 색상 바로 표시
- 빨간 배경 = 휴일, 주황 배경 = 작업자 휴가
- 이벤트 클릭 시 작업 상세 팝업

### 3.4 작업목록

전체 작업을 표로 조회합니다.

- 사이트·상태·키워드 검색, [검색조건 저장]으로 조건 보관
- 페이지당 20건, 하단에서 페이지 이동 및 총 건수 확인
- **[엑셀 다운로드]**: 조회된 전체 데이터를 CSV로 저장

### 3.5 작업 상세 팝업

어느 화면에서든 작업을 클릭하면 열립니다.

- **요청정보**: 요청내용 + 첨부파일 (등급 0·1은 파일 첨부 가능)
- **작업정보**: 담당자·우선순위·예상시간·유형·상태·시작/종료일시·일별 작업시간
- **상태변경이력**: 상태별 변경 시각과 작업기간 기록
- **[수정]**: 권한이 있으면 우선순위·예상시간·작업자·유형·상태·시작일시·
  요청내용 변경 (R·C·W 상태가 아니면 일부 항목은 잠김)

## 4. 관리자 화면

등급 0(관리자)·1(개발자)만 접근 가능합니다. 탭 순서:

`사이트 → 작업스케쥴 → 작업이력 → 작업상태변경이력 → 첨부파일 → 사용자 → 달력 → 작업자휴가`

새로고침 시 **작업스케쥴** 탭이 기본으로 열립니다.

### 공통 기능

- 각 탭 상단의 **검색라인**(사이트·상태·키워드)으로 목록 필터링
- **[검색조건 저장]**: 현재 필터를 브라우저에 저장, 다음 접속 시 자동 복원
- 아래 **입력라인**에서 신규 항목 등록
- 모든 목록 **페이지당 20건** + 총 건수 표시
- **[엑셀 다운로드/업로드]**: CSV로 내보내기·일괄 수정 반영

### 4.1 사이트

사이트(시스템/고객사) 등록·수정·삭제. 작업 등록 시 선택하는 사이트 목록을 관리합니다.

### 4.2 작업스케쥴 (기본 탭)

작업의 등록부터 상태·일정까지 한 곳에서 관리합니다.

- **입력라인**: 작업명·사이트·유형·우선순위·예상시간·작업자 지정 후 [추가]
  → 상태는 자동으로 **작업요청(R)**, 요청일시는 등록 시각으로 기록
- **목록 컬럼**: ID · 사이트 · 유형 · 작업명 · 우선순위 · 예상/실제 작업시간 ·
  상태 · CSR번호 · 현업담당자 · IT업무담당자 · 작업자 · 시작일시 ·
  종료일시(예상/실제)
- **셀 클릭 수정**: 유형·작업명·우선순위·예상시간·상태·CSR·담당자·작업자를
  행에서 바로 수정 (P·H·F·X 상태에서는 일부 항목 잠김 — §2 참고)
  - 현업담당자 셀은 이름을 입력하면 실시간으로 목록이 필터링됩니다
- **시작일시 클릭**: 시작일시 수동 설정 + **[고정]** 체크
  - 고정 시 재계산에도 시작일시가 유지됩니다
- **[재적용]**: 대기중 작업들의 일정을 우선순위 순으로 다시 자동 배치
- **[상세]**: 작업 상세 팝업 / **삭제**: R·C·W·H·X 상태에서만 가능
- **엑셀 업로드**: 다운로드한 CSV를 수정해 올리면 일괄 반영
  (실제 작업시간은 자동 집계라 업로드로 변경되지 않습니다)

### 4.3 작업이력

작업자가 실제 수행한 작업의 기록(일지)입니다. 상태 전이와 무관하게
작업자가 직접 등록하는 수동 기록입니다.

- 작업 선택 + 작업자 선택 + 작업내용 입력 → [등록]
- 등록 후에는 **작업내용만 수정** 가능 (작업·작업자는 변경 불가)
- 삭제 가능

### 4.4 작업상태변경이력

모든 작업의 상태 변경 기록입니다 (자동 생성, 수정 불가).

- 변경 시각 · 작업 · 변경 상태 · 작업기간(h) · 비고 표시
- 사이트·상태·키워드로 검색
- [전체삭제]: 이력 초기화 (주의 — 복구 불가)

### 4.5 첨부파일

작업에 첨부된 파일 목록을 관리합니다.

- 작업을 고르고 파일 선택 후 [업로드]
- 파일명 클릭 시 다운로드, 삭제 가능
- 사이트·작업 상태·키워드로 검색 가능

### 4.6 사용자

계정 승인과 정보를 관리합니다.

- **승인대기(A)** 사용자의 [승인]/[승인불가] 처리
  - 승인불가 시 사유 입력 가능 — 해당 사용자는 재신청 가능
- 이름·부서·연락처·등급·기본사이트 등 인라인 수정
- 비밀번호 초기화·사용자 삭제
- `admin` 행은 잠금(🔒 보호) — 어떤 사용자도 수정 불가

### 4.7 달력

전역 근무일력을 관리합니다.

- 좌측: 연도·월 선택 → 해당 월의 날짜별 근무일(W)/휴일(H) 지정
- 우측: 연도 입력 후 **[해당 연도 달력 생성]** → 1년치 날짜 일괄 생성
  (기본 평일=근무일, 주말=휴일)
- 달력에 없는 날짜는 월~금이 근무일로 간주됩니다

### 4.8 작업자휴가

작업자별 휴가 등록·관리 — 스케줄 계산에 반영됩니다.

- **A(종일)**: 해당일 전체 근무 제외
- **P(일부)**: 지정한 시간만큼 그날 근무시간 차감 (하루 뒤쪽부터 차감)
- 본인 휴가는 본인이, 등급 0·1은 모든 작업자의 휴가를 등록 가능

## 5. 자동 스케줄링 규칙

- **하루 근무시간**: 기본 09:00~12:00 + 13:00~18:00 (8시간,
  `WORK_SEGMENTS` 환경변수로 변경 가능 — 화면 상단에 표시)
- **비근무일**: 토·일 + 달력 탭에서 휴일(H)로 지정한 날
- **작업자 휴가**: 종일(A)은 근무 제외, 일부(P)는 시간 차감
- **배치 방식**: 작업자별로 우선순위 순 정렬 → 앞 작업이 끝나는 시점부터
  근무시간에 맞춰 시작/종료(예상) 자동 계산
- **시작일시 고정**: 고정된 작업은 재계산에도 시작일시 유지
- 작업 시작일시가 잡히면 예상시간을 근무시간 단위로 쪼개
  일별 작업시간(상세 팝업에서 확인)이 계산됩니다

## 6. 자주 묻는 상황

| 상황 | 방법 |
|------|------|
| 작업 등록 | 관리자 → 작업스케쥴 입력라인에서 추가 |
| 작업 진행 시작 | 상태를 대기중 → 작업중으로 변경 (목록 셀·칸반 드래그·상세 팝업) |
| 작업이 잠시 멈춤 | 작업중 → 작업중단, 재개 시 작업중단 → 작업중 |
| 요청 거절 | 작업반려(X)로 변경 (사유는 상태 비고에 기록) |
| 특정 날부터 시작 지정 | 작업스케쥴 시작일시 셀 클릭 → 일시 입력 + 고정 |
| 전체 일정 재조정 | 우선순위 수정 후 작업스케쥴의 [재적용] |
| 공휴일 지정 | 관리자 → 달력 탭에서 해당일을 휴일(H)로 |
| 연차·반차 등록 | 관리자 → 작업자휴가 탭 (반차는 P + 시간) |
| 작업일지 기록 | 관리자 → 작업이력 탭에서 작업내용 등록 |
| 파일 공유 | 작업 상세 팝업 → 첨부, 또는 관리자 → 첨부파일 탭 |
